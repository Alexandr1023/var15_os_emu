# Эмулятор UNIX-подобной командной оболочки

Практическая работа по конфигурационному управлению, вариант №15.

Программа запускает интерактивную оболочку с виртуальной файловой системой (VFS). Вся структура каталогов и файлов существует только в оперативной памяти процесса: команды никогда не изменяют реальную файловую систему пользователя.

## Требования и установка

Нужны Python 3.11 или новее и `pytest` для проверок. Зависимости устанавливаются командой:

```bash
python -m pip install -r requirements.txt
```

## Структура проекта

```text
src/shell_emulator.py  — реализация REPL и VFS
vfs_examples/          — XML-примеры VFS
scripts/               — стартовые TXT-сценарии
tests/                 — модульные и интеграционные тесты
run.sh                 — сценарий запуска
config.json            — конфигурация по умолчанию
```

## Запуск

```bash
./run.sh --vfs vfs_examples/nested.xml --script scripts/all_commands.txt
python -m src.shell_emulator --vfs vfs_examples/minimal.xml
```

Опция `--no-interactive` завершает работу после стартового сценария. Параметр `--script` задаёт TXT-файл команд; пустые строки и строки, начинающиеся с `#`, являются комментариями. `config.json` хранит параметры проекта по умолчанию.

## VFS в XML

Корень документа — `<vfs>`. В нём и в каталогах допустимы `<directory name="...">` и `<file name="...">`. Текстовый файл сохраняется как UTF-8, а для произвольных байтов применяется `encoding="base64"`:

```xml
<vfs>
  <directory name="home">
    <file name="hello.txt" encoding="base64">SGVsbG8hCg==</file>
  </directory>
</vfs>
```

Поддерживаются абсолютные и относительные пути, а также `.` и `..`. XML загружается в память и не перезаписывается командами программы.

## Команды

| Команда | Назначение |
| --- | --- |
| `ls [путь]` | вывести содержимое каталога |
| `cd [путь]` | сменить текущий каталог VFS |
| `pwd` | показать текущий путь |
| `cat <путь>` | вывести текстовый файл |
| `history` | показать историю команд сеанса |
| `mv <источник> <назначение>` | переместить или переименовать файл/каталог |
| `vfs-info` | показать источник загруженной VFS и SHA-256 |
| `vfs-init` | создать пустую VFS в памяти |
| `exit` | выйти из REPL |

Пример сеанса:

```text
vfs:/$ cd /home/student
vfs:/home/student$ cat hello.txt
Hello from VFS!
vfs:/home/student$ mv hello.txt greeting.txt
```

Ошибочные пути, конфликт имён и попытка переместить каталог внутрь себя обрабатываются сообщениями об ошибках без остановки REPL.

## Тестирование

Одна команда запускает все тесты, включая запуск CLI и операции с несколькими XML-VFS:

```bash
python -m pytest -q
```
